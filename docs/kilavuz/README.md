# PİA-DENT kısa kullanım kılavuzları (Görev 14)

Rol başına bir sayfa; ekran görüntüleri sentetik demo verisinden (`apps/web/e2e/screens-tur.mjs` ile üretilir, `docs/kilavuz/img/`). Pilot eğitiminde (`pilot-checklist.md` §5) basılır ya da ekranda açılır. Gerçek klinik adı/logosu/metni içermez; pilot klinik kendi içeriğini (katalog, şablon) Yönetim'den tanımlar.

| Rol | Kılavuz | Süre |
|---|---|---|
| Sekreter | [sekreter.md](sekreter.md) | ~1 saat eğitim |
| Hekim | [hekim.md](hekim.md) | ~45 dk |
| Finans | [finans.md](finans.md) | ~45 dk |
| Klinik yöneticisi | [yonetici.md](yonetici.md) | ~1 saat |

Ortak: giriş `E-posta + parola` (+ etkinse 6 haneli kod ya da kurtarma kodu); 90 dk boşta kalınca oturum düşer; tarihler gg.aa.yyyy, takvim simgesi ya da `Alt+↓` ile açılır; üst çubuktaki arama her ekrandan hastaya götürür. **Sistem çalışmazsa:** kâğıt randevu listesi + sonra giriş (`pilot-checklist.md` §5 başvuru kartı).

**Görünüm (02.11.2026).** Üst çubuktaki palet simgesi (veya Hesabım → Görünüm): 7 vurgu rengi, Açık / Loş / Koyu / Cihaz ayarı, 5 yazı ölçeği. Yalnız sizin hesabınız için; tüm cihazlarınızda geçerli. Logo değişmez. Telefonda geniş tablolar otomatik kart görünümüne geçer.
